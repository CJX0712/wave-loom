# 坍缩织机 · Wave Loom

Wave Function Collapse 的可视化织机。不靠随机堆砌图案，靠**约束**让图案自己长出来 —— 而且把「熵、约束传播、冲突、回溯」整套过程摊开给你看。

单个 HTML 文件，双击即用。零依赖、零构建、**完全离线**，不联网、不上传。

## 怎么用

下载 `index.html` → 双击打开 → 选个纹样 → 看它一格一格织出来。

- **暂停 / 单步**：想看清每一步发生了什么，就用单步
- **立刻织完**：跳过动画直接看结果
- **换**：换随机种子（同一种子必定织出同一张图）
- **熵热图**：深色 = 候选少、快定下来了；浅色 = 还很自由。关掉就只看成品
- **环面**：首尾相接，织出可以无限平铺的图案
- **导出 PNG / JSON**：JSON 里是每格的图块 id + 全部统计量

## 算法：每步只做三件事

每一格一开始都「同时是所有可能的图块」，这就是波形还没坍缩的状态。

1. **选格** —— 挑候选最少的那一格（熵最小）。信息越少的地方越该先定，因为它最容易把别人逼到无路可走。
2. **坍缩** —— 按预设权重随机挑一个图块定下来。权重决定风格：弯管多就是迷宫，直管多就是电路板。
3. **传播** —— 这一格定了，四条边就把邻居的候选集削一遍；被削过的邻居再去削它的邻居，直到不再变化。屏幕上那层涟漪就是这一步。

「能不能挨着」在开局就预计算成了兼容表：`compat[方向][图块A]` 存的是所有能在该方向与 A 相接的图块集合。传播时把邻居候选集和它取交集，交集为空就是**冲突**。

冲突了先**回溯**：回退到上一个存档点，把刚才的错误选择划掉重挑。存档点只保留最近 300 步，回不去了才整局重织。

## 两种图块集

### 边标签式 —— 管道 / 迷宫 / 结绳 / 地牢

每条边取 0 或 1（连通 / 不连通），穷举全部 **16 种**组合。因为组合是完备的，任何边的组合都找得到图块，所以这四个预设零冲突。同一个图块集，换个权重、换个画法，就是四种完全不同的纹样：

| 预设 | 权重倾向 | 结果 |
|---|---|---|
| 管道回路 | 直通权重最高 | 电路板走线，长直段多 |
| 迷宫回廊 | 拐角压倒性高，几乎禁掉十字三通 | 通道一路绕，出不来回路 |
| 凯尔特结 | 同管道，但用穿过中心的曲线画 | 长段绕成编织绳结 |
| 地牢房间 | 墙（空白）权重极高，十字留余地 | 大片墙里长出成片房间 |

### 高度图块式 —— 等高地形

四个角各取「深水 / 浅滩 / 陆地」三档高度，并且**一格内高度差不允许超过一级**。

这条限制是整套东西的关键：3⁴ = 81 种组合因此只剩 **31 种**，跨格的高度也被迫平滑过渡，才长得成连片大陆和海岸线。

> 如果一开始把 81 种全放开，约束就退化成「共享角一致」，WFC 会退化成格点随机场 —— 配合最小熵优先，坍缩会沿直线级联，织出来的是规则的斜条纹，根本不是地形。这是开发过程中真实踩到的坑：第一版就是完备的 16 种二值角图块，输出全是 `#.#.#.#.#.`。

顺带说明：对角上的两个角不受同一条边约束，理论上可能顶死 —— 比如左上已是深水、右下已是陆地，跨了两级，31 个图块里没有一个是这样，冲突就发生了。这个缝很窄，所以「冲突 / 回溯」计数器多数时候是 0，但正是它保证织机不会卡死在半路。

地形用 **marching squares** 渲染：先铺深水，再叠「高度 ≥1」的浅滩，最后叠「高度 ≥2」的陆地并描出海岸线。

## 确定性

所有随机都来自种子驱动的 `mulberry32`。同一个种子 + 同一套设置，织出来的图案**逐格一致**，可以直接复现 —— 导出的 JSON 里也带了种子。

## 局限

- **完备图块集不会产生约束冲突，也就没有「纠错」的余地**，四个二进制预设的图案质量完全由权重决定。想让 WFC 真正「聪明」起来，需要精心设计的图块集（地形那一档就是例子）
- **回溯是近似的**：回退时只是把刚失败的那个选择划掉，不是严格的完备回溯。好处是绝不死锁，代价是理论上可能错过某些解
- 网格最大 72 列；再大建议直接用「立刻织完」（60 列 2100 格约 1 秒）
- 它织的是**自洽的图案**，不是「好看的图案」。想调风格就调权重

## 本地验证

仓库不含测试框架，验证脚本在开发时是一次性的。改动后想在浏览器控制台里自查：

```js
const p = PRESETS[0];                       // 换别的预设就改下标
const w = new WFC({
  cols: 30, rows: 18,
  tiles: tilesOf(p), weights: weightsOf(p),
  seed: 12345, periodic: false
});
while (!w.done && !w.failed) w.step();
w.validate()   // { ok: true } —— 逐格检查四条边是否真和邻居对得上
w.conflicts    // 冲突次数
w.avgOptions() // 未坍缩格的平均候选数
```

`validate()` 是判断有没有织坏的唯一标准：它会遍历每一对相邻格，确认共享的那条边标签相等。
